## Readiness Stations

- [ ] Hand sink is stocked and used only for its approved purpose.
- [ ] Three-compartment sink order is demonstrated: wash, rinse, sanitize.
- [ ] Approved sanitizer is mixed or verified using current directions.
- [ ] Test strip is read and compared with the instructor-confirmed range.
- [ ] Thermometer is calibrated using the approved ice-bath procedure.
- [ ] Student explains what happens when a thermometer is inaccurate.
- [ ] Approved thawing methods are identified; unsafe shortcuts are rejected.
- [ ] Practice label includes all instructor-required information.
- [ ] FIFO placement is demonstrated.
- [ ] Dish flow, towel routing, storage, and restricted areas are located.
- [ ] Grease-fire response and extinguisher location are explained without operating emergency equipment.
- [ ] Station is reset for the next group.
