# Culinary 2 Semester 2 Module Map

The [Modular Pacing Guide](01_Modular_Pacing_Guide.md) is the single governing year sequence. The [Semester 2 weekly guide](06_Semester_2_Weekly_Guide.md) supplies its weekly planning view.

| Flexible span | Learning and applications |
| --- | --- |
| 19–23 | Reset retained skills, baking/bread timing, mock service and readiness-based spring operations. Spring C1 Week 4 stays training; shared public opening normally targets C1 Week 5, overall Week 23. C2-only service requires adequate staffing and instructor authorization. |
| 24–28 | Valentine’s chocolates, pasta depth, authorized wok cooking, regional seafood/component timing and Pi Day pies. Actual event dates move the applications. |
| 29–32 | Five-course tasting-menu planning, component tests, simplification, repetition and complete service rehearsal. |
| 33–34 | Preferred Explore Charleston execution in Week 33; Week 34 emergency buffer and debrief. Actual partner availability remains open. |
| 35–36 and adopted post-guide buffer | Scoped Teacher Appreciation work if feasible, individual evidence, testing, inventory, care and shutdown. No new required technical unit. |

Baking, regional foods and student favorites are spread across the year rather than reserved for this semester. Existing equipment makes pastry and frozen-dessert applications possible, but availability is not a requirement to cover every method. Bread/starter responsibility transfers only through explicit instruction and assignment; no new external sourdough program is adopted. All applications include dishes, storage and reset. The confirmed capstone is not an open choice among unrelated projects.
